Cross-entropy loss

L = − ∑k yk log(pk)  =  −log(pcorrect class)

def cross_entropy(P, Y, eps=1e-12):
    P = np.clip(P, eps, 1 - eps)
    return np.mean(-np.sum(Y * np.log(P), axis=1))

Why not accuracy

Accuracy's gradient is zero almost everywhere — nudging a weight slightly almost never flips a prediction. Cross-entropy changes continuously with every probability shift, so gradient descent always has a signal to follow.

Numerical stability checklist

  • Clip probabilities away from exactly 0 and 1 before log.
  • Subtract the row max before exp in softmax (Lesson 2) — keeps values from overflowing before they even reach the loss.
