Backprop Hidden-Layer Cheatsheet

The complete backward pass for a 2-layer network, output to input. From Lesson 5.

The full backward pass

dZ2 = (P - Y) / batch
dW2 = A1.T @ dZ2
db2 = dZ2.sum(axis=0)

dA1 = dZ2 @ W2.T
dZ1 = dA1 * (Z1 > 0)
dW1 = X.T @ dZ1
db1 = dZ1.sum(axis=0)

Two kinds of backward step

Forward opBackward opMixes units?
Matmul (@)Matmul with a transposeYes — weighted combination
Element-wise (ReLU, etc.)Element-wise (*)No — each unit independent

Transpose-and-flip rule for matmul gradients

Given Y = X @ W, and an incoming gradient dY (same shape as Y):

dX = dY @ W.T
dW = X.T @ dY

Whichever input you're not solving for gets transposed; shape reasoning confirms which side it goes on.

ReLU derivative

relu'(z) = 1 if z > 0 else 0
dZ = dA * (Z > 0)

Dead ReLU: if Z < 0 for a unit across the whole batch, its gradient is exactly zero and it stops learning. Watch for this during real training.
