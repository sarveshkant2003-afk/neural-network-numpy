NumPy Foundations Cheatsheet

The array operations you'll reach for constantly while building a network. Keep this open while coding. From Lesson 1.

Creating arrays

CallGives you
np.array([1, 2, 3])1-D array from a Python list
np.zeros((3, 4))3×4 array of zeros
np.ones((3, 4))3×4 array of ones
np.random.randn(3, 4)3×4 array, standard-normal random values — how you'll initialize weights
np.eye(3)3×3 identity matrix

Inspecting an array

AttributeMeaning
a.shapetuple of dimension sizes, e.g. (3, 4)
a.ndimnumber of dimensions (1 = vector, 2 = matrix)
a.dtypeelement type, e.g. float64
a.reshape(4, 3)same data, new shape (must have same total size)

Element-wise ops (shapes must match, or broadcast)

a + b, a - b, a * b, a / b, a ** 2, np.exp(a), np.maximum(a, 0) — every one of these applies the operation independently to each matching element. * is never matrix multiplication in numpy.

Broadcasting rule

Compare shapes from the right. Two dimensions are compatible if they're equal, or one of them is 1. Missing dimensions on the left count as 1.

Shape AShape BResult
(3, 4)(4,)(3, 4) — B is applied to every row
(3, 1)(1, 4)(3, 4) — both stretch
(3, 4)(3,)error — 4 vs 3 don't match and neither is 1

This is exactly how a bias vector b of shape (n,) gets added to every row of a batch of shape (batch, n) without writing a loop.

Matrix multiplication

CallMeaning
A @ Bmatrix multiplication (preferred, Python 3.5+)
np.dot(A, B)same as @ for 2-D arrays
np.matmul(A, B)same as @, generalizes to batches of matrices
A.Ttranspose

Rule: (m, n) @ (n, p) → (m, p). The inner dimensions must match — identical to the linear algebra you already know.

Reductions

CallMeaning
a.sum()sum of all elements → scalar
a.sum(axis=0)sum down each column
a.sum(axis=1)sum across each row
a.mean(axis=0)mean down each column

Preview: one linear layer

W = np.random.randn(n_out, n_in) * 0.01   # weights
b = np.zeros(n_out)                        # bias
z = W @ x + b                              # linear step
a = np.maximum(z, 0)                       # ReLU activation
