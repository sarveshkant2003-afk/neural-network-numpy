MNIST Data Cheatsheet

Loading, scaling, splitting, and encoding real digit data. From Lesson 7.

Load

from sklearn.datasets import fetch_openml
X, y = fetch_openml('mnist_784', version=1, return_X_y=True, as_frame=False)
y = y.astype(int)

Shapes

ArrayShapeMeaning
X(70000, 784)70k images, each a flattened 28×28
y(70000,)integer digit label, 0-9

Preprocess

X = X / 255.0                       # pixels -> range [0, 1]

rng = np.random.default_rng(0)
shuffle = rng.permutation(len(X))
X, y = X[shuffle], y[shuffle]

n_test = 10000
X_train, X_test = X[:-n_test], X[-n_test:]
y_train, y_test = y[:-n_test], y[-n_test:]

Y_train = np.zeros((len(y_train), 10))
Y_train[np.arange(len(y_train)), y_train] = 1

Why each step

StepReason
Divide by 255keeps numbers small, same motivation as small weight init
Shuffle before splitraw file isn't randomly ordered by label
Hold out a test setthe only way to catch memorization instead of learning
One-hot the training labelsmatches the cross-entropy loss shape from Lesson 3
Keep test labels as plain intscompared directly against predicted class, no one-hot needed

Always look before you train

plt.imshow(X_train[0].reshape(28, 28), cmap='gray')
plt.title(str(y_train[0]))

Catches mislabeled or malformed data in seconds, before it silently wrecks a training run.
