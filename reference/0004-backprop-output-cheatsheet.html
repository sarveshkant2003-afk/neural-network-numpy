Backprop Output-Layer Cheatsheet

The softmax+cross-entropy gradient, and the shape-reasoning trick for turning it into weight/bias gradients. From Lesson 4.

The one to memorize

∂L/∂Z = P − Y

Gradient of cross-entropy loss w.r.t. the pre-softmax logits. All exponentials cancel. This is why softmax and cross-entropy are paired by default.

dZ2 = (P - Y) / batch          # shape (batch, n_out)

Shape-reasoning rule

A gradient always has the same shape as the quantity it's the gradient of. Given the forward equation, the backward matmul order is whichever one produces that shape — usually unique.

ForwardBackwardWhy this order
Z2 = A1 @ W2 + b2dW2 = A1.T @ dZ2only order giving (n_hidden, n_out)
db2 = dZ2.sum(axis=0)broadcast forward → sum backward

General rule for biases

Broadcasting forward becomes summation backward, over the broadcast axis. A bias added to every row of a batch (broadcast over axis=0) gets its gradient summed over axis=0.

Sanity check, every time

After writing any new gradient line, print its shape next to the shape of the parameter it corresponds to. They must match exactly.

print(dW2.shape, W2.shape)   # must be identical
print(db2.shape, b2.shape)   # must be identical
