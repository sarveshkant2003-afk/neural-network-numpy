Forward Pass Cheatsheet

Broadcasting rule and the batched-layer convention, for quick lookup while coding. From Lesson 2.

Broadcasting: the 3-step check

  1. Right-align both shapes; pad the shorter with 1s on the left.
  2. Each dimension pair must be equal, or one of them must be 1.
  3. Result shape = elementwise max of the (padded) shapes.
ABResult
(32, 5)(5,) → (1, 5)(32, 5)
(32, 5)(32, 1)(32, 5)
(3, 1)(1, 2)(3, 2) (outer)
(32, 5)(4,)error — 5 ≠ 4

Common bug: forgetting keepdims=True on a reduction. Z.max(axis=1) gives shape (32,), which broadcasts wrong. Z.max(axis=1, keepdims=True) gives (32, 1), which broadcasts right.

Batched layer convention

SymbolShape
X (input batch)(batch, n_in)
W (weights)(n_in, n_out)
b (bias)(n_out,)
Z = X @ W + b(batch, n_out)

Note this is W transposed relative to Lesson 1's single-example convention (W was (n_out, n_in) there, used as W @ x).

Activation functions

def relu(Z):
    return np.maximum(Z, 0)

def softmax(Z):
    shifted = Z - Z.max(axis=1, keepdims=True)
    exp = np.exp(shifted)
    return exp / exp.sum(axis=1, keepdims=True)

A full layer stack (MNIST-shaped)

A1 = relu(X  @ W1 + b1)      # (batch, 784) -> (batch, 128)
probs = softmax(A1 @ W2 + b2)  # (batch, 128) -> (batch, 10)
