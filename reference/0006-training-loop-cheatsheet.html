Training Loop Cheatsheet

The update rule, and the full step in one place. From Lesson 6.

The update rule (do this for every parameter)

W -= lr * dW
b -= lr * db

Subtract because the gradient points toward more loss. Going the opposite way makes the loss smaller.

Picking a learning rate

SymptomLikely cause
Loss bounces around, never settleslr too big
Loss barely moves after many stepslr too small
Loss falls smoothlyreasonable lr — try 0.1 as a starting point

One full training step

Z1 = X @ W1 + b1
A1 = relu(Z1)
Z2 = A1 @ W2 + b2
P  = softmax(Z2)
loss = cross_entropy(P, Y)

dZ2 = (P - Y) / batch
dW2 = A1.T @ dZ2
db2 = dZ2.sum(axis=0)
dA1 = dZ2 @ W2.T
dZ1 = dA1 * (Z1 > 0)
dW1 = X.T @ dZ1
db1 = dZ1.sum(axis=0)

W1 -= lr * dW1
b1 -= lr * db1
W2 -= lr * dW2
b2 -= lr * db2

Words worth knowing

TermMeans
Stepone pass through the block above
Epochone pass through the entire training set (same as a step, if you use the whole dataset every time, as here)
Learning ratehow big each step is
