Scaled weight init

def init_weights(n_in, n_out, rng):
    return rng.standard_normal((n_in, n_out)) * np.sqrt(1.0 / n_in)

More inputs → smaller individual weights, so their sum stays reasonable. A simplified Xavier/He init.

Mini-batching

def iterate_batches(X, Y, batch_size, rng):
    n = X.shape[0]
    order = rng.permutation(n)
    for start in range(0, n, batch_size):
        idx = order[start:start + batch_size]
        yield X[idx], Y[idx]
TermMeans
Batchone small chunk of the data, e.g. 128 images
Stepone forward + backward + update, on one batch
Epochone full pass over all batches — the whole dataset once

The full loop

for epoch in range(epochs):
    for Xb, Yb in iterate_batches(X_train, Y_train, batch_size, rng):
        # forward (Lesson 2)
        Z1 = Xb @ W1 + b1; A1 = relu(Z1)
        Z2 = A1 @ W2 + b2; P = softmax(Z2)
        # backward (Lessons 4-5)
        n = Xb.shape[0]
        dZ2 = (P - Yb) / n
        dW2 = A1.T @ dZ2; db2 = dZ2.sum(axis=0)
        dA1 = dZ2 @ W2.T; dZ1 = dA1 * (Z1 > 0)
        dW1 = Xb.T @ dZ1; db1 = dZ1.sum(axis=0)
        # update (Lesson 6)
        W1 -= lr * dW1; b1 -= lr * db1
        W2 -= lr * dW2; b2 -= lr * db2
