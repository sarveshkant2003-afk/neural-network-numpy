Lesson 6 · Neural Networks from Scratch

Gradient Descent: Actually Training the Network

Here's where everything you've built so far pays off. You can measure how wrong the network is (the loss), and you know exactly which way to nudge every number to make it a little less wrong (the gradients). This lesson takes those nudges and turns them into real training — you'll watch a loss number go down, step by step, in front of you.

The idea, in plain terms

Picture standing on a hill in thick fog, trying to get to the bottom. You can't see the whole landscape. But you can feel which way is downhill from right where you're standing. So you take a small step that way, feel again, take another small step, and repeat. Eventually you reach the bottom.

That's gradient descent. The "hill" is the loss. Your position is the current values of all the weights. "Feeling which way is downhill" is exactly what the gradient tells you — except a gradient actually points uphill, toward higher loss. So to go downhill, you step in the opposite direction.

The update rule

For every single number in the network — every weight, every bias — the update is the same simple move:

new_value = old_value - (learning_rate * gradient)

In code, applied to all four parameter groups:

W1 -= lr * dW1
b1 -= lr * db1
W2 -= lr * dW2
b2 -= lr * db2

That's it. That's the entire "learning" part of a neural network — repeated, over and over, thousands of times.

What's this "learning rate" (lr)?

It's just how big a step you take each time. It's a number you pick, like 0.1.

  • Too big a step: you overshoot the bottom of the hill, land somewhere worse, overshoot again the other way — the loss bounces around instead of settling down.
  • Too small a step: you'll get there eventually, but it takes forever.

In practice you just try a value, watch what the loss does, and adjust. 0.1 is a reasonable starting guess for the kind of network you're building.

One step, all together

A single training step is just everything from Lessons 2 through 5, run back to back: forward pass, loss, backward pass, then the update above. Nothing new here — just gluing together pieces you already built:

# forward (Lesson 2)
Z1 = X @ W1 + b1
A1 = relu(Z1)
Z2 = A1 @ W2 + b2
P  = softmax(Z2)

# loss (Lesson 3)
loss = cross_entropy(P, Y)

# backward (Lessons 4-5)
dZ2 = (P - Y) / batch
dW2 = A1.T @ dZ2
db2 = dZ2.sum(axis=0)
dA1 = dZ2 @ W2.T
dZ1 = dA1 * (Z1 > 0)
dW1 = X.T @ dZ1
db1 = dZ1.sum(axis=0)

# update (new, this lesson)
W1 -= lr * dW1
b1 -= lr * db1
W2 -= lr * dW2
b2 -= lr * db2

Training is just: do that a lot of times

One step barely moves the loss. So you put it in a loop and run it hundreds or thousands of times, checking in on the loss every so often to see it fall:

for step in range(num_steps):
    ... run the whole block above ...
    if step % 20 == 0:
        print(f"step {step}, loss {loss}")

Each pass through the loop is called a step (or, when it covers the whole dataset once, an epoch — we're using the whole toy dataset every step below, so here the two mean the same thing).

Your tangible win

Create code/train.py. First, a little helper that makes a small, easy dataset — points clustered into 3 groups, so the network has something real (if simple) to learn:

import numpy as np

def make_toy_dataset(n_per_class=50, n_features=4, n_classes=3, seed=0):
    rng = np.random.default_rng(seed)
    centers = rng.uniform(-3, 3, size=(n_classes, n_features))
    X, labels = [], []
    for c in range(n_classes):
        pts = centers[c] + rng.normal(scale=0.5, size=(n_per_class, n_features))
        X.append(pts)
        labels += [c] * n_per_class
    return np.vstack(X), np.array(labels)

Then the full training script — this is everything from all five previous lessons, plus the update rule, in one place:

def relu(Z):
    return np.maximum(Z, 0)

def softmax(Z):
    shifted = Z - Z.max(axis=1, keepdims=True)
    exp = np.exp(shifted)
    return exp / exp.sum(axis=1, keepdims=True)

def cross_entropy(P, Y, eps=1e-12):
    P = np.clip(P, eps, 1 - eps)
    return np.mean(-np.sum(Y * np.log(P), axis=1))

np.random.seed(0)
n_in, n_hidden, n_out = 4, 8, 3
X, labels = make_toy_dataset(n_features=n_in, n_classes=n_out)

Y = np.zeros((len(labels), n_out))
Y[np.arange(len(labels)), labels] = 1

W1 = np.random.randn(n_in, n_hidden) * 0.1
b1 = np.zeros(n_hidden)
W2 = np.random.randn(n_hidden, n_out) * 0.1
b2 = np.zeros(n_out)

lr = 0.1
batch = X.shape[0]

for step in range(201):
    Z1 = X @ W1 + b1
    A1 = relu(Z1)
    Z2 = A1 @ W2 + b2
    P  = softmax(Z2)
    loss = cross_entropy(P, Y)

    dZ2 = (P - Y) / batch
    dW2 = A1.T @ dZ2
    db2 = dZ2.sum(axis=0)
    dA1 = dZ2 @ W2.T
    dZ1 = dA1 * (Z1 > 0)
    dW1 = X.T @ dZ1
    db1 = dZ1.sum(axis=0)

    W1 -= lr * dW1
    b1 -= lr * db1
    W2 -= lr * dW2
    b2 -= lr * db2

    if step % 20 == 0:
        acc = (P.argmax(axis=1) == labels).mean()
        print(f"step {step:4d}  loss {loss:.4f}  accuracy {acc:.2f}")

Run it. Watch the loss number fall and the accuracy climb toward 1.00 over the 200 steps — that's a real, working neural network, learning, built entirely with numpy. This is the moment everything since Lesson 1 has been building toward.

Once it works, try breaking it on purpose: set lr = 5 and watch the loss go haywire instead of settling down. Then try lr = 0.001 and watch it barely move in 200 steps. Seeing both failure modes makes the "too big / too small" explanation above stick a lot better than just reading it.
