NumPy Foundations: The Substrate of Every Layer

Every weight matrix, activation, and gradient in the network you're about to build is a numpy array. Before writing a single neuron, you need fluency in the handful of array operations everything else sits on top of.

Why this comes first

You already know the linear algebra: matrix multiplication, transposes, dot products. That's not the gap. The gap is numpy's way of expressing it — and one idea, broadcasting, that has no direct equivalent in the linear algebra you learned on paper. This lesson maps what you know onto numpy syntax, then spends most of its time on the one genuinely new concept.

The ndarray

A numpy array (ndarray) is a grid of numbers of one dtype. Three attributes you'll check constantly:

import numpy as np

x = np.array([[1., 2., 3.],
              [4., 5., 6.]])

x.shape   # (2, 3) -- 2 rows, 3 columns
x.ndim    # 2
x.dtype   # dtype('float64')

Almost every bug you'll hit while building the network is a shape mismatch. Get in the habit of printing .shape after every new line of array code until it's automatic.

Element-wise ops vs. matrix multiplication

This is the single most common source of silent bugs in from-scratch neural network code. In numpy, * is never matrix multiplication — it's element-wise.

SyntaxComputesShape requirement
A * Belement-wise productsame shape (or broadcastable)
A @ Bmatrix multiplication(m, n) @ (n, p) → (m, p)
A.Ttranspose(m, n) → (n, m)

The @ operator is exactly the matrix multiplication you already know: inner dimensions must agree, just as on paper.

Broadcasting: the new idea

Broadcasting lets numpy apply an operation between arrays of different shapes, by virtually stretching the smaller one — without copying data or writing a loop. The rule: compare shapes from the right; two dimensions are compatible if they're equal, or one of them is 1.

Z = np.random.randn(32, 5)   # a batch of 32 examples, 5 features each
b = np.zeros(5)              # one bias per feature

Z + b   # shape (32, 5) -- b is added to every one of the 32 rows

This is precisely how a single bias vector gets added to an entire batch in one line, with no explicit loop over rows. You'll use this pattern every time you add a bias term.

Your tangible win

If numpy isn't installed yet, run pip install numpy in your terminal first. Then, in VS Code, create code/forward_pass.py and write the forward pass of one linear layer plus a ReLU activation — the exact computation every layer of your eventual network will perform:

import numpy as np

np.random.seed(0)

n_in, n_out = 4, 3
x = np.random.randn(n_in)              # one input example
W = np.random.randn(n_out, n_in) * 0.1  # weight matrix
b = np.zeros(n_out)                     # bias vector

z = W @ x + b            # linear step
a = np.maximum(z, 0)     # ReLU activation

print("x shape:", x.shape)
print("W shape:", W.shape)
print("z:", z)
print("a (after ReLU):", a)

Run it. Before you do, predict z.shape and a.shape on paper from the matmul rule above — then check yourself against the output. If they match, you've just computed the exact operation that happens in every layer, forward pass, of the network you're about to build.
